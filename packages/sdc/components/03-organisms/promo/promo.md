title: 'Promo'

Use a promo to draw attention to a single item (a publication, event, program, or page) with a visual and a short call to action. The component pairs an image with a heading, brief description, and link.

## When to use

- you want to draw attention to one specific item within a page or sidebar
- the item has an image that adds context and visual interest
- a single clear call to action follows from the featured content

## When not to use

- to feature more than one item – use a card grid or [Feature link list](/components/feature-link-list/) for multiple items
- when no suitable image is available – a promo without an image loses its visual purpose
- as the page header – use [Banner](/components/banner/) instead
- for process content – use [Timeline](/components/timeline/) for ordered steps

## Related components

- [Campaign](/components/campaign/) – use for a major editorial feature rather than a single highlighted item.
- [Feature link list](/components/feature-link-list/) – use to present a group of related navigational links.
- [Banner](/components/banner/) – use as the page-level header rather than an in-page feature.
